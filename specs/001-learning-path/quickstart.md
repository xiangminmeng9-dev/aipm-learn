# 快速开始: AI 生成个人学习路径

**日期**: 2026-04-30 | **分支**: `001-learning-path`

## 集成场景

### 场景 1: 生成学习路径

1. 用户从 AI 技能树侧边栏点击"AI 学习路径"
2. 进入学习路径页面，看到"生成学习路径"按钮
3. 系统自动获取用户弱项数据，调用 AI 生成个性化学习路径
4. 页面展示推荐模块列表，按优先级排序

### 场景 2: 查看历史记录

1. 用户从 AI 技能树侧边栏点击"路径历史"
2. 进入历史页面，看到所有学习路径记录列表
3. 点击某条记录展开查看详情

### 场景 3: 数据看板

1. 用户进入设置数据看板
2. 在技能树模块统计区域看到学习路径生成次数和推荐模块总数

## 依赖

- AI 技能树侧边栏 (SkillsSidebar.tsx) 需确认/添加导航项
- 首页技能树卡片 (page.tsx) 需确认 subFeature
- AI 客户端 (claude.ts) 的 generateText 函数
- AI 提示词 (prompts.ts) 需添加学习路径 prompt
- Supabase 数据库需创建 learning_paths 表
- 技能树数据 (skill_modules) 提供弱项信息
- 面试弱项数据提供补充弱项信息
- 设置数据看板 (dashboard/page.tsx) 需添加学习路径统计
- 学习仪表板 API (learning/dashboard/route.ts) 需添加学习路径数据
