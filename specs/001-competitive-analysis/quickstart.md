# 快速开始: 竞品分析助手

**日期**: 2026-04-30 | **分支**: `001-competitive-analysis`

## 集成场景

### 场景 1: 生成竞品分析

1. 用户从面试助手侧边栏点击"竞品分析"
2. 进入竞品分析页面，看到产品名输入框
3. 输入产品名（如"飞书"），点击"生成分析"
4. 系统调用 AI 生成四维度分析报告
5. 页面展示结构化报告和评分

### 场景 2: 查看历史记录

1. 用户从面试助手侧边栏点击"竞品历史"
2. 进入历史页面，看到所有分析记录列表
3. 点击某条记录展开查看详情

### 场景 3: 数据看板

1. 用户进入设置数据看板
2. 在面试模块统计区域看到竞品分析次数和平均得分

## 依赖

- 面试助手侧边栏 (Sidebar.tsx) 需添加导航项
- 首页面试助手卡片 (page.tsx) 需添加 subFeature
- AI 客户端 (claude.ts) 的 generateText 函数
- AI 提示词 (prompts.ts) 需添加竞品分析 prompt
- Supabase 数据库需创建 competitive_analyses 表
- 设置数据看板 (dashboard/page.tsx) 需添加竞品分析统计
- 学习仪表板 API (learning/dashboard/route.ts) 需添加竞品分析数据
